# Título

Para reproduzir a obra de referência, utilizei o Adobe Illustrator para medir os elementos da imagem e identificar as suas proporções e posições, facilitando a composição para o p5.js. deicidi definir o fundo a preto e posicionar os retângulos coloridos sobre ele, em vez de desenhar as linhas pretas separadamente, permitindo controlar os espaços entre os elementos através das coordenadas de cada retângulo. Utilizei rect() por ser adequado às formas geométricas da composição e fill() para definir as cores através de valores RGB, recorri aos ciclos for e à função map() para criar os degradês amarelo e azul e uma sombra gradual na parte inferior da composição, variando progressivamente as cores e a transparência, Por fim utilizei random() para distribuir pequenos pontos pretos com transparência, procurando reproduzir a textura granulada da referência, e noLoop() para que o desenho fosse executado apenas uma vez pesquisando sobre me pareceu a melhor opção quando entendi que o computador repetia o desenho várias vezes, também acrescentei comentários com // para registar o que ia aprendendo sobre cada função e explicar a sua utilidade, esta prática ajudou-me a organizar o código, a não me perder durante o processo e a compreender melhor as decisões tomadas.
