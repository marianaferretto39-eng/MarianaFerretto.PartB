# Título
O random(1) gera um número aleatório entre 0 e 1. O if verifica se esse número é maior do que 0,5 e, se for, o retângulo fica vermelho (fill(238, 36, 0)). Caso contrário, o else faz com que fique branco (fill(237, 241, 237)). O rect() desenha o retângulo com a cor escolhida. Ao retirar o noLoop(), a função draw() repete-se continuamente, gerando novos números aleatórios e fazendo o retângulo alternar entre vermelho e branco, criando o efeito de piscar.
