# Título
O elemento generativo escolhido foi piscar o retangulo vermelho usando o random, quis desistabilizar a obra sutilmente sem alterar a ordem das coisas, usei o random(1) para gerar um número aleatório entre 0 e 1. Depois, com o if e o else, defini que, se o número fosse maior que 0,5, o retângulo ficaria vermelho; caso contrário, ficaria branco, por fim tive que tirar o noLoop porque se não o retangulo vermelho não iria piscar aleatoriamente.
